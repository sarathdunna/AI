# SVM Implementation for Pulsar Classification

A linear Support Vector Machine built from scratch by solving the dual quadratic program with CVXOPT, used to classify pulsar stars. Test accuracy reaches 98% for C ≥ 10.

> The maintained version of this project, with a full write-up, is in **[sarathdunna/AI-SVM](https://github.com/sarathdunna/AI-SVM)**.

## Run it

```bash
pip install numpy pandas scikit-learn cvxopt
python "SVM Implementation for Pulsar Classification.py"
```

**Tech:** Python, NumPy, CVXOPT, pandas, scikit-learn
